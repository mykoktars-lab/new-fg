# Finish Good Analysis — Update v2.1

## Perubahan
- Pembacaan OCR diarahkan per baris secara horizontal: Line I, II, III, dan seterusnya.
- Untuk setiap Line, kode flavour dibaca dari kolom flavour Shift 1, Shift 2, dan Shift 3 sesuai posisi kolom pada tabel.
- Jika ada beberapa token dalam satu sel (contoh kode dengan angka), token digabung.
- OCR tidak mengarang pembagian shift bila koordinat kata tidak tersedia; pengguna dapat mengoreksi data secara manual.
- Desain diperbarui menjadi gradasi hitam-kuning/emas.
- Logo dan video pengenalan dihapus dari aplikasi.
- Data tetap disimpan lokal di browser perangkat.
